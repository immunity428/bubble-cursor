# 実験データの比較ページ

実験アプリ（`../experiment`）で保存した生データ（JSON）を複数読み込み、参加者ごとに対にして比較します。
`index.html` を Chrome で開き、JSON をドロップするか「JSONを読み込む」で選ぶだけで使えます（サーバー不要・データは外部に送信されません）。

区間の計算には実験アプリと同じ `../experiment/js/analysis.js` を使うので、**`experiment/` と同じ階層に置いたまま**開いてください。

## できること

| 画面 | 内容 |
| --- | --- |
| 読み込んだデータ | 参加者・実施日時・条件の順番・区間数・エイム命中数・画面サイズ・設定の一覧。チェックを外すと集計から除外 |
| 注意 | 画面サイズ・バブルの最大半径・エイム設定・アンケートの構成が参加者で違うとき、条件の順番が偏っているとき、途中で終わったデータがあるときに表示 |
| 比較 | 課題（アンケート／エイム区間／エイム成績）と、比べるもの（バブルなし/あり、または1回目/2回目）を選ぶと、全指標の比較表と参加者ごとの対の図を表示 |
| 参加者ごとの値 | 比較に使っている、参加者 × グループごとの代表値 |
| Fitts の法則 | エイム課題の区間を難易度 ID と移動時間で散布図にし、条件ごとに MT = a + b·ID を当てはめ |
| 軌跡を並べて見る | 2つのデータ（初期値は同じ参加者のなし/あり、同じページ）の軌跡と回答点を左右に並べる |

停止とみなす間隔・最大速度の窓を変えると、生データから全部計算し直します。

## 統計の中身

- 参加者ごとの代表値：区間の指標は**中央値**、空振り・誤選択・回答の変更は**合計**、エイム成績はラウンドの値
- 検定：**Wilcoxon 符号順位検定（対応あり・両側）**。差が 0 の参加者は除く。差のある人数が 25 人以下は正確な分布、それより多いと正規近似（連続性補正つき）
- 効果量：r = |Z| / √N
- 「1回目 / 2回目」で比べると、条件に関係なく**順序効果（慣れ）**があるかを確かめられる

`stats.js` の結果は scipy の `wilcoxon` と一致することを確認しています。
